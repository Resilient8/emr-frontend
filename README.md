# 🏥 EMR (Electronic Medical Record System)

## ✨ Key Features
*   🩺 **Doctor:** Diagnosis tools, ICD-10 coding, and prescription management.
*   💉 **Nurse:** Patient registration, vital signs recording, and initial symptom assessment.
*   💊 **Pharmacist:** Real-time prescription queue, medication dispensing, and auto-stock deduction.
*   🛡️ **Admin:** Master data management (users, medicines, ICD-10) and system monitoring.

---

## 🛠️ Technology Stack
*   **Frontend:** Vue.js 3 (Composition API), Quasar Framework, Pinia, Vue Router
*   **Backend:** Node.js, Express.js
*   **Database:** MySQL with Sequelize ORM
